# PTE Vocab Learner 📚

一个轻量、离线可用的 **PTE Academic 单词学习道具**。

专为 PTE 备考设计的简单闪卡工具，支持中英对照、随机练习、进度记录。

## 功能

- 🎴 单词闪卡（点击翻转查看释义）
- 🔀 随机打乱顺序
- ✅ 标记已掌握 / 未掌握
- 📊 简单进度统计
- 📱 手机友好
- 离线可用（打开一次后即可离线使用）

## 在线使用

开启 GitHub Pages 后访问：

**https://ddx-9.github.io/pte-vocab-learner/**

## 本地使用

1. 下载或 clone 本仓库
2. 用浏览器打开 `index.html` 即可

## 推荐配合使用的资源

| 资源 | 说明 | 链接 |
|------|------|------|
| **qwerty-learner** | 专业打字背单词，含大量 PTE 词库（Basic / Advanced / FIB / WFD 等） | [GitHub](https://github.com/RealKai42/qwerty-learner) |
| **pte-3000-words** | PTE 前 3000 高频词，带遗忘曲线 + 跟读 | [GitHub](https://github.com/1745761934/pte-3000-words) |
| Academic Word List (AWL) | 学术核心词 570 词族 | 搜索 AWL |

## 词库说明

当前内置约 150 个高频 PTE / 学术核心单词（含中文释义）。

后续可以自己扩展 `words.js` 文件。

## 如何开启 GitHub Pages

1. 进入仓库 Settings → Pages
2. Source 选择 `Deploy from a branch`
3. Branch 选 `main`，文件夹选 `/ (root)`
4. 保存后等待 1 分钟即可访问
